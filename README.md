# copypaste

Finder에서 파일을 복사(⌘C)하면 같은 Tailscale 계정의 기기에서만 열리는 다운로드 링크가 클립보드에 함께 들어갑니다.

```
Finder에서 build.zip ⌘C
 ├ Finder에 ⌘V            → 평소처럼 파일이 붙여넣어짐
 └ 메모·주소창 등에 ⌘V     → https://<이 Mac>.ts.net:8765/s/<토큰>/build.zip
```

- 파일은 복사해 두지 않고 원본 경로만 기억합니다. 받는 순간 원본을 그대로 보냅니다.
- 폴더나 여러 항목은 받을 때 zip 하나로 묶입니다.
- 링크는 24시간 뒤 만료됩니다. 같은 파일을 다시 복사하면 같은 링크가 연장됩니다.
- `https://<이 Mac>.ts.net:8765/` 에서 최근 공유 목록을 볼 수 있습니다. 상대 Mac에 즐겨찾기해 두면 링크를 옮길 필요가 없습니다.

## 설치

두 Mac에서 각각 실행합니다. Tailscale 앱이 로그인되어 있고 HTTPS 인증서가 켜져 있어야 합니다.

```bash
./install.sh
```

`~/Applications/Copypaste.app` 으로 설치되고 로그인할 때 자동 실행됩니다. 제거는 `./uninstall.sh` 입니다.

Swift 컴파일러가 없는 Mac에서는 `build/Copypaste.app` 이 들어 있는 폴더째로 옮긴 뒤 `./install.sh` 를 실행하면 빌드 없이 설치됩니다.

## 메뉴 막대

링크 아이콘을 누르면 최근 공유(누르면 링크 텍스트만 복사), 일시 정지, 공유 목록 페이지, 모든 링크 끊기, 종료가 있습니다.
메신저처럼 파일 붙여넣기를 우선하는 앱에 링크를 넣고 싶을 때는 "최근 공유"에서 항목을 눌러 링크만 복사하세요.

## 보안

- 서버는 `127.0.0.1` 에만 열리고, 바깥으로는 `tailscale serve`(tailnet 전용, 인터넷 비공개)로만 나갑니다.
- 요청마다 Tailscale이 붙여 주는 로그인 계정이 이 Mac의 소유 계정과 같은지 확인합니다. 같은 tailnet의 다른 사용자, 공유받은 기기, 태그 기기는 거부됩니다. 계정을 확인할 수 없으면 거부합니다.
- Host 헤더가 이 Mac의 tailnet 주소가 아니면 거부합니다(웹페이지의 DNS 리바인딩, 로컬 포트 직접 접근 차단).
- 링크 토큰은 약 130비트 난수입니다. 서버는 등록된 경로만 내보내며 URL의 경로는 파일 위치로 쓰지 않습니다.
- `~/.ssh`, `~/.aws`, `~/.gnupg`, 키체인, `.env`, `*.pem`, `*.key` 등은 복사해도 링크를 만들지 않습니다(`isSensitive` 참고).
- 비밀번호 관리자 등이 "기록 금지"로 표시한 클립보드 내용은 읽지 않습니다.
- 한계: 이 Mac에 로그인한 다른 macOS 사용자가 헤더를 꾸며 로컬 포트에 접근하는 것까지는 막지 못합니다. 혼자 쓰는 Mac을 전제로 합니다.

## 기존 동작에 대한 안전장치

- 클립보드의 모든 항목이 파일일 때만 손댑니다. 텍스트·이미지 복사는 건드리지 않습니다.
- 원본 클립보드 데이터를 전부 읽은 뒤 텍스트 부분만 바꿔 다시 씁니다. 하나라도 읽지 못하거나 그 사이 클립보드가 바뀌면 그대로 둡니다.
- 포트 8765에 이미 다른 `tailscale serve` 설정이 있으면 덮어쓰지 않습니다.

## 설정 (환경 변수)

| 변수 | 기본값 | 뜻 |
| --- | --- | --- |
| `COPYPASTE_PORT` | 8765 | tailnet에 노출되는 HTTPS 포트 |
| `COPYPASTE_LOCAL_PORT` | 48765 | 로컬 서버 포트 |
| `COPYPASTE_TTL_HOURS` | 24 | 링크 유지 시간 |

로그는 `~/Library/Logs/copypaste.log` 에 남습니다.
