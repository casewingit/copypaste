# copypaste

Finder에서 파일을 복사(⌘C)하면 같은 Tailscale 계정의 기기에서만 열리는 다운로드 링크가 클립보드에 함께 들어갑니다.

```
Finder에서 build.zip ⌘C
 ├ Finder에 ⌘V            → 평소처럼 파일이 붙여넣어짐
 └ 메모·주소창 등에 ⌘V     → https://<이 Mac>.ts.net:8765/s/<토큰>/build.zip
```

- 파일은 복사해 두지 않고 원본 경로만 기억합니다. 받는 순간 원본을 그대로 보냅니다.
- 폴더나 여러 항목은 받을 때 zip 하나로 묶입니다.
- 링크는 24시간 뒤 만료됩니다. 같은 파일을 다시 복사하면 같은 링크가 연장됩니다.
- `https://<이 Mac>.ts.net:8765/` 에서 최근 공유 목록을 볼 수 있습니다. 상대 Mac에 즐겨찾기해 두면 링크를 옮길 필요가 없습니다.

## 필요한 것

- macOS 13 이상 (Apple Silicon, Intel 모두 지원)
- [Tailscale](https://tailscale.com/download) 앱이 설치되어 로그인된 상태 (독립 실행판, App Store판, Homebrew판 모두 가능)
- tailnet에서 **MagicDNS와 HTTPS 인증서**가 켜져 있어야 합니다. [관리 화면의 DNS 설정](https://login.tailscale.com/admin/dns)에서 켤 수 있습니다. 꺼져 있으면 설치 프로그램과 메뉴 막대가 켜는 주소를 알려 줍니다.
- 사용자 계정으로 로그인된 기기여야 합니다. 태그된 기기(소유 계정 없음)에서는 동작하지 않습니다.

## 설치

파일을 주고받을 Mac마다 한 번씩 설치합니다.

1. [Releases](../../releases/latest)에서 `Copypaste-<버전>.dmg` 를 받아 엽니다.
2. 열린 창에서 **Copypaste 아이콘을 응용 프로그램(Applications) 폴더로 끌어다 놓습니다.**
3. 응용 프로그램 폴더에서 Copypaste를 엽니다.

처음 열 때 macOS가 "확인되지 않은 개발자"라며 막습니다(Apple 공증을 받지 않은 앱이기 때문입니다). 한 번만 허용하면 됩니다.

- **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 "Copypaste" 항목 옆 **그래도 열기**를 누릅니다.
- 또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/Copypaste.app` 을 실행한 뒤 다시 엽니다.

열리면 안내 창이 한 번 뜨고 메뉴 막대에 링크 아이콘이 생깁니다. 로그인할 때 자동으로 실행되도록 등록되며, 메뉴에서 끌 수 있습니다. 관리자 권한은 필요 없습니다.

- **업데이트**: 새 DMG의 앱을 응용 프로그램 폴더에 덮어쓴 뒤 다시 엽니다. 예전 방식(`install.sh`)으로 설치했던 것은 처음 열 때 자동으로 정리됩니다.
- **제거**: 메뉴 막대 아이콘 → **Copypaste 제거…** 를 누르면 자동 실행 등록, Tailscale 공유 설정, 공유 목록을 지우고 앱을 휴지통으로 옮깁니다. 앱만 휴지통에 버리면 Tailscale 공유 설정이 남습니다.
- **소스에서 빌드**: 저장소를 받아 `bash install.sh` (Xcode 명령줄 도구 필요). DMG는 `bash scripts/make-dmg.sh` 로 만듭니다.

### 처음 쓸 때 macOS가 묻는 것

- 문서·데스크탑·다운로드 폴더의 파일을 처음 공유할 때 폴더 접근 허용을 묻습니다. 허용해야 그 폴더의 파일을 내려보낼 수 있습니다. 앱을 업데이트하면 다시 물을 수 있습니다.
- 복사할 때마다 "붙여넣기 허용"을 묻는다면 시스템 설정 → 개인정보 보호 및 보안 → 다른 앱에서 붙여넣기에서 Copypaste를 "허용"으로 바꾸세요.

### 문제 해결

메뉴 막대 아이콘이 ⚠︎ 로 바뀌면 메뉴 맨 위에 원인이 나옵니다. 자세한 내용은 메뉴의 "로그 보기"(`~/Library/Logs/copypaste.log`)에 있습니다.

| 증상 | 해결 |
| --- | --- |
| "HTTPS/Serve를 켜야 합니다" | 안내된 주소를 열어 tailnet에서 HTTPS를 켭니다 |
| "포트 8765를 다른 tailscale serve 설정이 쓰고 있습니다" | `defaults write com.copypaste.agent port -int 9000` 실행 후 앱을 종료했다가 다시 열기 |
| "Tailscale에 로그인되어 있지 않거나 꺼져 있습니다" | Tailscale을 켜고 로그인 |
| 링크는 생기는데 다른 기기에서 403 | 그 기기가 같은 Tailscale 계정으로 로그인되어 있는지 확인 |

## 메뉴 막대

링크 아이콘을 누르면 최근 공유(누르면 링크 텍스트만 복사), 일시 정지, 공유 목록 페이지, 모든 링크 끊기, 종료가 있습니다.
메신저처럼 파일 붙여넣기를 우선하는 앱에 링크를 넣고 싶을 때는 "최근 공유"에서 항목을 눌러 링크만 복사하세요.

## 보안

누가 받을 수 있나:

- 서버는 `127.0.0.1` 에만 열리고, 바깥으로는 `tailscale serve`(tailnet 전용)로만 나갑니다. 인터넷에는 공개되지 않습니다(Funnel 미사용).
- 요청마다 Tailscale이 붙여 주는 로그인 계정이 이 Mac의 소유 계정과 같은지 확인합니다. 같은 tailnet의 다른 사용자, 공유받은 기기, 태그 기기는 거부됩니다. 계정을 확인할 수 없으면 거부합니다. 이 헤더는 `tailscale serve`가 덮어쓰므로 요청자가 꾸밀 수 없습니다.
- Host 헤더가 이 Mac의 tailnet 주소가 아니면 거부합니다(웹페이지의 DNS 리바인딩 차단).
- 로컬 포트는 `tailscale serve`만 아는 무작위 비밀 경로로 들어온 요청만 받습니다. 같은 Mac의 다른 사용자나 샌드박스 앱이 헤더를 꾸며 로컬 포트로 직접 접근해도 통과하지 못합니다.
- 링크 토큰은 약 130비트 난수입니다. 서버는 등록된 경로만 내보내며 URL의 경로는 파일 위치로 쓰지 않습니다.
- 동시 연결 수와 요청 대기 시간에 상한이 있습니다.

무엇이 공유되지 않나:

- `~/.ssh`, `~/.aws`, `~/.gnupg`, 키체인, `.env`, `*.pem`, 개인 키 형식의 `*.key` 등은 복사해도 링크를 만들지 않습니다. 홈 폴더 전체, `~/Library` 처럼 이런 폴더를 통째로 품은 상위 폴더도 마찬가지입니다(`isSensitive` 참고).
- 심볼릭 링크는 실제 위치로 풀어서 판단하고, 내려보내는 시점에도 다시 확인합니다.
- 폴더를 zip으로 묶을 때 안에 든 위 종류의 파일은 빠집니다. 단, 폴더 안의 `*.key` 는 Keynote 문서와 구분할 수 없어 포함됩니다.
- 비밀번호 관리자 등이 "기록 금지"로 표시한 클립보드 내용은 읽지 않습니다.

알고 써야 하는 것:

- Finder에서 복사한 파일은(위 예외를 빼고) 모두 24시간 동안 같은 계정의 기기에서 받을 수 있게 됩니다. 같은 Tailscale 계정에 로그인된 기기가 탈취되면 그 기기에서도 받을 수 있으므로, 잃어버린 기기는 Tailscale 관리 화면에서 바로 제거하세요. 메뉴 막대의 "모든 공유 링크 끊기"와 "일시 정지"로 즉시 막을 수 있습니다.
- 이 Mac에서 같은 사용자 계정으로 실행되는 악성 프로그램까지는 막지 못합니다(그런 프로그램은 이미 파일을 직접 읽을 수 있습니다).
- 링크는 클립보드에 들어가므로 클립보드 기록 앱이나 공통 클립보드에도 남습니다. 링크만으로는 받을 수 없고 계정 확인을 통과해야 합니다.
- Tailscale HTTPS 인증서는 공개 인증서 투명성 로그에 기록되어 기기의 tailnet 이름(`<기기>.<tailnet>.ts.net`)이 공개됩니다. 이름만 공개되며 접속은 되지 않습니다.
- 릴리스의 앱은 임시(ad-hoc) 서명이고 Apple 공증을 받지 않아, 처음 열 때 macOS의 확인 절차를 한 번 거쳐야 합니다. 릴리스 노트의 SHA-256으로 확인하거나 소스에서 직접 빌드하세요.

취약점은 GitHub의 비공개 보안 제보(Security → Report a vulnerability)로 알려 주세요.

## 기존 동작에 대한 안전장치

- 클립보드의 모든 항목이 파일일 때만 손댑니다. 텍스트·이미지 복사는 건드리지 않습니다.
- 원본 클립보드 데이터를 전부 읽은 뒤 텍스트 부분만 바꿔 다시 씁니다. 하나라도 읽지 못하거나 그 사이 클립보드가 바뀌면 그대로 둡니다.
- 포트 8765에 이미 다른 `tailscale serve` 설정이 있으면 덮어쓰지 않습니다.

## 설정

터미널에서 값을 바꾼 뒤 앱을 종료했다가 다시 엽니다. 예: `defaults write com.copypaste.agent ttlHours -int 2`

| 키 | 기본값 | 뜻 |
| --- | --- | --- |
| `port` | 8765 | tailnet에 노출되는 HTTPS 포트 |
| `localPort` | 48765 | 로컬 서버 포트 |
| `ttlHours` | 24 | 링크 유지 시간 |

## 자원 사용

대기 중에는 메모리 약 35~45MB, CPU 0%입니다(클립보드 변경 여부만 0.4초마다 확인). 파일은 1MB씩 읽어 보내므로 수 GB 파일을 보내도 메모리 사용량이 늘지 않습니다. 폴더는 임시 파일 없이 바로 압축해 보냅니다. 로그는 1MB를 넘으면 자동으로 줄입니다.
